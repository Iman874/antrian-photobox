## 🔒 Overlay Wajib Aktifkan Suara

**Masalah**: Browser modern (iOS Safari, Chrome mobile) memblokir audio otomatis — butuh user gesture sebelum audio bisa diputar.

**Solusi**:
- Saat client buka halaman antrian, tampil **overlay full-screen** yang memblokir seluruh halaman
- Client **wajib** tap overlay sebelum bisa mengakses halaman antrian
- Setelah tap, audio di-unlock via Web Audio API + HTML Audio element (kompatibel iOS Safari)
- Overlay dihapus total setelah tap, halaman antrian bisa dipakai normal
