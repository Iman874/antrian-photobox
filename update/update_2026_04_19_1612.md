## 🔤 Fix: Nama Client dengan Huruf Kapital Semua Dibaca Terbata-bata di TTS

**Masalah**: Ketika nama client menggunakan huruf kapital semua (contoh: "RARA", "BUDI"), sistem text-to-speech (TTS) malah membaca nama tersebut huruf per huruf alih-alih sebagai kata utuh.
- Contoh error: "RARA" dibaca "R-A-R-A" bukan "Rara"
- Ini adalah perilaku standar Google TTS API ketika menerima teks all-caps

**Penyebab**: Google TTS mendeteksi teks all-caps sebagai akronim/singkatan dan masuk ke "spelling mode" yang membaca setiap huruf terpisah.

**Solusi**: Konversi nama ke Title Case (huruf pertama setiap kata besar, sisanya kecil) sebelum dikirim ke TTS API:
- Tambah fungsi helper `toTitleCase()` di semua halaman yang menggunakan TTS
- Fungsi ini mengubah: "RARA" → "Rara", "SITI NURHALIZA" → "Siti Nurhaliza"
- Tidak ada perubahan di tampilan UI — hanya affect TTS output
- Tidak ada perubahan di database atau server logic

## Implementasi Fungsi toTitleCase()

```javascript
function toTitleCase(str) {
    if (!str) return '';
    return str.toLowerCase().split(/\s+/).map(word => 
        word.charAt(0).toUpperCase() + word.slice(1)
    ).join(' ');
}
```

### Contoh Perubahan TTS Text:

**Sebelum:**
```javascript
const text = `Nomor antrian ${number} atas nama ${name}, segera ke Monobox sekarang`;
// Jika name = "RARA" → "Nomor antrian 01 atas nama RARA..." → Dibaca R-A-R-A
```

**Sesudah:**
```javascript
const text = `Nomor antrian ${number} atas nama ${toTitleCase(name)}, segera ke Monobox sekarang`;
// Jika name = "RARA" → "Nomor antrian 01 atas nama Rara..." → Dibaca "Rara" (benar!)
```
